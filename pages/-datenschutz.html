Kurzfassung
ServeLoad verwendet kein eigenes Tracking und setzt selbst keine Cookies zu Analyse- oder Werbezwecken.

Hosting über GitHub Pages
Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website verarbeitet GitHub technisch erforderliche Daten. Nach Angaben von GitHub wird insbesondere die IP-Adresse von Besuchern zu Sicherheitszwecken protokolliert und gespeichert.

Zweck der Verarbeitung
Die Verarbeitung technisch erforderlicher Zugriffsdaten dient der sicheren und zuverlässigen Bereitstellung der Website sowie dem Schutz der verwendeten Infrastruktur.

Kontakt per E-Mail
Wenn du per E-Mail Kontakt aufnimmst, werden die von dir übermittelten Daten ausschließlich verwendet, um deine Anfrage zu bearbeiten und darauf zu antworten. Welche Daten dabei verarbeitet werden, hängt davon ab, welche Informationen du selbst in der Nachricht übermittelst.

Speicherdauer
ServeLoad speichert keine eigenen Zugriffsprotokolle der Website. Für Daten, die durch GitHub Pages verarbeitet werden, gelten die jeweiligen Speicher- und Datenschutzregelungen von GitHub. E-Mail-Anfragen werden nur so lange aufbewahrt, wie dies für die Bearbeitung und gegebenenfalls erforderliche Anschlusskommunikation notwendig ist.

Deine Rechte
Dir können nach der Datenschutz-Grundverordnung insbesondere Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung und gegebenenfalls Widerspruch zustehen. Außerdem besteht grundsätzlich das Recht, sich bei einer zuständigen Datenschutz-Aufsichtsbehörde zu beschweren.
